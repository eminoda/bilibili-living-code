/tickets/:ticketID/close

## 关闭工单 

### 请求URL

https://xxx.com/api.php/v2/tickets/:ticketID/close
### 请求头

名称 类型 必填 描述

token string 是 访问凭证Token
### 请求体

名称 类型 必填 描述

closedReason string 是 关闭原因(commented 已处理 | repeat 重复 | refuse 不予处理) 
comment string 是 备注
### 请求示例

```text
{
 "closedReason": "done"
}
```

### 请求响应

名称 类型 描述

status string 状态(success 成功 | fail 失败)
### 响应示例

```text
{
 "status": "success"
}
```
