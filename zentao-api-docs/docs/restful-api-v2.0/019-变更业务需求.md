## 变更业务需求 

### 请求URL

https://xxx.com/api.php/v2/epics/:epicID/change
### 请求头

名称 类型 必填 描述

token string 是 访问凭证Token
### 请求体

名称 类型 必填 描述

title string 否 需求名称 
reviewer array 是 评审人员 
spec string 否 需求描述 
verify string 否 验收标准
### 请求示例

```text
{
 "title": "智能头枕颈椎检测",
 "reviewer": [
 "admin"
 ],
 "spec": "描述",
 "verify": "验收标准"
}
```

### 请求响应

名称 类型 描述

status string 状态(success 成功 | fail 失败)
### 响应示例

```text
{
 "status": "success"
}
```
