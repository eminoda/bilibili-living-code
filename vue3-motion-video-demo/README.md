# Vue3 + Motion-v 视频演示项目

本项目配合视频《Vue3+Motion-v：告别手搓动画，让质感起飞！》，通过 Vue 3 与 Motion for Vue 展示交互动画和宝可梦球体转场。

## 演示内容

- `src/plus/PokeballWalkthrough.vue`：分步骤演示宝可梦球体变形与展开转场。
- `src/animate/`：旋转、进出场、布局变化和手势动画示例。
- `src/plus/`：转场阶段、背景、B 站互动效果与动效逻辑。

## 启动

需要 Node.js `^22.18.0` 或 `>=24.12.0`。

```sh
cd vue3-motion-video-demo
pnpm install
pnpm dev
```
