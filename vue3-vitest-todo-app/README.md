# vue3-vitest-todo-app

在 Todo 项目中添加 Vitest 单元测试与浏览器测试，项目包含 Vue 前端与 Mock Server。

来源分支：course005-vitest-in-5-minutes。

## 运行

从工作流仓库根目录运行：

~~~sh
pnpm --filter @living/vue3-vitest-todo-app dev
~~~

测试命令：pnpm --filter @living/vue3-vitest-todo-app test --run。另开终端进入 apps/living-projects/vue3-vitest-todo-app/mock-server，运行 npm start 启动本地接口服务。
