# vue3-tanstack-query-todo-app

使用 TanStack Query 管理服务端 Todo 数据，项目包含 Vue 前端与 Mock Server。

来源分支：course004-tanstack-query-in-5-minutes。

## 运行

从工作流仓库根目录运行：

~~~sh
pnpm --filter @living/vue3-tanstack-query-todo-app dev
~~~

另开终端进入 apps/living-projects/vue3-tanstack-query-todo-app/mock-server，运行 npm start 启动本地接口服务。
